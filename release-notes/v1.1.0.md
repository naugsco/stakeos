# StakeOS v1.1.0

A larger feature and quality release: a full accessibility + visual-consistency
pass across the dashboard, new ministering and member-profile MCP tools, clearer
Windows setup, and developer-experience fixes.

## Highlights

### Accessibility
- Visible keyboard-focus indicator across the whole app; honors the system
  reduced-motion preference (no more perpetually pulsing stale-sync alert).
- Charts are now screen-reader accessible: each has a descriptive label and a
  hidden data table, so the underlying numbers are reachable without a mouse.
- Member Groups filter now closes on Escape or an outside click, announces itself
  to assistive tech, and returns focus to its trigger.
- Higher-contrast caption text for sync timestamps and chart notes.
- Friendly loading skeletons and a clear error screen (with a link to Sync Center)
  for the data-backed pages.

### New MCP tools
- **ministering_assignments** — the ministers assigned to a member.
- **reverse_ministering_lookup** — which households a given minister covers.
- **member_profile** — a 360° card (callings, household, spouse, ministering,
  recommend status, convert/RM flags) in a single call.
- **upcoming_birthdays** — birthdays in the next N days, filterable by unit and age.
- **unit_ministering_coverage** — companionship-level coverage for a ward/branch.

### Design consistency
- Unified color, border, and corner-radius tokens; shared button/panel building
  blocks; refreshed navigation with a clearer active state.
- Cross-platform fonts so the app looks consistent on macOS and Windows.

### Windows & developer experience
- Rewritten, step-by-step Windows setup guide aimed at non-coders.
- The dev server now self-heals the local database engine after a desktop build,
  so `npm run dev` no longer crashes with a native-module version mismatch.

## Install Notes

- Download the `.dmg` for the standard macOS install flow.
- Use the `.zip` if the DMG is blocked or you need the app bundle directly.
- If macOS blocks first launch, right-click the app and choose **Open**.
- Windows users: see
  [WINDOWS_DASHBOARD_SETUP.md](https://github.com/naugsco/stakeos/blob/main/WINDOWS_DASHBOARD_SETUP.md).

## Suggested Validation

- Tab through the dashboard and confirm a visible focus ring on every link/button.
- Open the Members → Member Groups filter and confirm Escape and outside-click both close it.
- Ask the StakeOS MCP for a `member_profile` and `unit_ministering_coverage` and confirm the data matches the dashboard.
- Confirm charts still render correctly across Overview / Action Needed / Trends.
