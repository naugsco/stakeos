# StakeOS v1.0.19

## Highlights

- Centralized StakeOS date parsing for LCR-style dates such as `9 Apr 2026` and ISO dates.
- Fixed Recent Baptisms and Recent Baptism Readiness Cohort dashboard/report filtering and sorting so April baptisms and other LCR text dates are included correctly.
- Fixed MCP baptism and new-member contact tools so baptism and move-in windows are evaluated from parsed raw SQLite member dates.
- Fixed temple recommend expiration risk reports so raw `temple_recommend_expiration_date` values are parsed before expired, next-30-day, and 31-90-day buckets are computed.
- Fixed youth, seminary, institute, unit health, unit readiness, and youth-transition reports so LCR `birthdate` values no longer break age eligibility counts.
- Fixed calling tenure, calling-date UI sorting, and advanced MCP timeline sorting to use the shared date parser.

## Install Notes

- Download the `.dmg` for the standard macOS install flow.
- Use the `.zip` if the DMG is blocked or you need the app bundle directly.
- If macOS blocks first launch, right-click the app and choose **Open**.

## Suggested Validation

- Check the Recent Baptism Readiness Cohort and Recent Baptisms reports for April 2026 baptisms.
- Check the temple recommend expiration risk report for expired and next-90-day records.
- Check seminary/institute participation and unit readiness dashboard counts.
- Ask the StakeOS MCP for recent baptism and new-member contact lists and confirm the date windows match the dashboard.
