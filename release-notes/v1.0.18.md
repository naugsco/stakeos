# StakeOS v1.0.18

## Highlights

- Fixed StakeOS MCP recent baptism tools so `recent_baptism_report` and `recent_baptism_contact_list` filter against the raw member `baptismDate` value correctly.
- Fixed `new_member_contact_list` move-in filtering so it parses the raw SQLite `members.move_in_date` field instead of relying on SQLite text-date comparison.
- Kept report output dates unchanged while making the filtering and default date sorting tolerate LCR-style date strings.

## Install Notes

- Download the `.dmg` for the standard macOS install flow.
- Use the `.zip` if the DMG is blocked or you need the app bundle directly.
- If macOS blocks first launch, right-click the app and choose **Open**.

## Suggested Test After Updating

- Ask the StakeOS MCP for `recent_baptism_report`, `recent_baptism_contact_list`, and `new_member_contact_list` with a 12-month window and confirm recent baptisms and move-ins are included as expected.
