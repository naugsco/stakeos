# StakeOS v1.1.1

A packaging fix release. v1.1.0 failed to launch with a server-side exception
on some machines; this release corrects the native database module so the app
starts reliably.

## Highlights

### Fixes
- **Fixed launch crash ("Application error: a server-side exception has
  occurred").** The packaged build shipped the SQLite engine compiled for the
  wrong runtime (system Node instead of the Electron runtime the app uses),
  causing an `ERR_DLOPEN_FAILED` error on startup. The release build now rebuilds
  the native module for Electron before packaging, so the shipped binary always
  matches the runtime.

No feature or data changes since v1.1.0 — the MCP tools, dashboard, and reports
are unchanged.

## Install Notes

- Download the `.dmg` for the standard macOS install flow.
- Use the `.zip` if the DMG is blocked or you need the app bundle directly.
- If macOS blocks first launch, right-click the app and choose **Open**.
- Windows users: see
  [WINDOWS_DASHBOARD_SETUP.md](https://github.com/naugsco/stakeos/blob/main/WINDOWS_DASHBOARD_SETUP.md).

## Suggested Validation

- Launch the app and confirm the dashboard loads without the "server-side
  exception" error.
- Confirm Sync Center and the data-backed pages render (these exercise the
  SQLite engine that previously failed to load).
