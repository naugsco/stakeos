# StakeOS v1.0.15

## Highlights

- Added persistent Training Group Follow-Up status on Stake Overview, including `Draft opened`, `Mark Sent`, and resend detection when the follow-up queue changes.
- Fixed the unit/calling sync bug that collapsed all leadership callings into one ward and corrected the Unit Health leadership metrics.
- Improved report-side unit resolution so leadership and calling counts prefer the linked member unit instead of stale calling-unit metadata.

## Install Notes

- Download the `.dmg` for the normal macOS install flow.
- Use the `.zip` if you need the app bundle directly.
- This build is not notarized. If macOS blocks first launch, right-click the app and choose **Open**.
