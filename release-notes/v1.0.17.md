# StakeOS v1.0.17

## Highlights

- Hardened LCR custom report parsing for browser rendering differences between Safari and Chromium.
- Added support for LCR machine-style column names such as `record.preferred.name`, `record.individual.email`, and `custom-reports.unit`.
- Fixed duplicated LCR header/value prefixes so scraped values are cleaned before they enter the local SQLite database.
- Added parser verification fixtures for both friendly report labels and Chromium machine labels.
- Fixed repeated-text cleanup so numeric values like age `11` are not accidentally collapsed to `1`.

## Install Notes

- Download the `.dmg` for the standard macOS install flow.
- Use the `.zip` if the DMG is blocked or you need the app bundle directly.
- If macOS blocks first launch, right-click the app and choose **Open**.

## Suggested Test After Updating

- Run a calling sync from Sync Center and confirm members, units, emails, phone numbers, and callings populate normally.
