# LCR Custom Report Setup

StakeOS needs an LCR custom report that returns **one row per person**.

You will paste the report URL into StakeOS during first setup.

## Important Rules

- Column order does not matter
- Column names do matter
- The report must stay person-based, not household-based
- Use the full custom-report details URL
- Do not rename headers

Unit names in StakeOS are populated from the synced report data. You do not need to manually configure each ward or branch.

## Fastest Path

If you already know how to build the report in LCR:

1. Create the report
2. Include the columns below
3. Copy the full report details URL
4. Paste it into StakeOS

StakeOS also includes an in-app helper during setup with copyable column groups.
